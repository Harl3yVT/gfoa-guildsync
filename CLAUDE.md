# Rules for Claude in this repo

Read `CONTRIBUTING.md` before changing anything. In short:

- If you are helping Sephya: edit only `GayFurriesLeaderboard/`, work on a `sephya/<topic>` branch, run the tests,
  bump the leaderboard `.toc` version, open a PR to `main`. Never push to `main`, push tags or create releases
  (a `v*` tag publishes to CurseForge).
- Keep the saved data shape, the `GPVPLB` comm prefix and the code marked `-- GFoA` (details in CONTRIBUTING.md).
- WoW Forever: interface 16001; `UnitName`'s second value is a surname, not a realm.
- The repo is public: no secrets or personal info.
